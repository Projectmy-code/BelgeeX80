# 🚗 BELGEE X80 Club Portal

**Полноценная экосистема, база знаний и CMS для владельцев кроссовера BELGEE X80.**

## 📖 О проекте

Этот проект создан для объединения владельцев автомобилей BELGEE X80. Здесь каждый автовладелец может найти проверенные артикулы запчастей, прочитать гайды по ремонту, скачать 3D-модели для печати или посмотреть машину в интерактивном 3D-конфигураторе. 

---

## 🚀 Ключевые возможности

*   📦 **Каталог запчастей:** База OEM-номеров и проверенных аналогов (расходники, масла, свечи) с умным поиском и копированием артикулов.
*   📝 **Блог и База знаний:** Полноценные статьи с визуальным редактором (Quill), загрузкой обложек и системой модерации контента.
*   🧊 **3D Конфигуратор:** Интерактивный шоурум на базе Three.js. Позволяет вращать автомобиль и примерять заводские цвета кузова (Geely EX5).
*   🖨️ **3D-Печать:** Библиотека моделей в форматах STL и 3MF с автоматической генерацией 3D-превью и встроенным просмотрщиком.
*   ✅ **Чек-лист приёмки:** Интерактивный список для проверки автомобиля при получении в салоне (с сохранением прогресса).
*   👑 **Собственная CMS:** Панель администратора с Live-режимом (видно, кто из админов онлайн), медиабиблиотекой, конструктором страниц и управлением меню.
*   👤 **Личный кабинет:** Профиль пользователя с историей его статей и отправленных 3D-моделей.
