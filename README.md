# BELGEE X80 — сайт с модерацией

## Установка
1. Создайте проект в Supabase (https://supabase.com).
2. Откройте SQL Editor и выполните `supabase/schema.sql`.
3. В `js/config.js` укажите Project URL и **publishable/anon** key. Никогда не указывайте service_role/secret key.
4. В Supabase Authentication настройте Site URL и redirect URLs для адреса сайта. Включите подтверждение email (рекомендуется).
5. Опубликуйте папку на HTTPS-хостинге (Netlify, Vercel, обычный хостинг с поддержкой статических файлов). Для локальной проверки запустите `python3 -m http.server 8000` в папке проекта и откройте `http://localhost:8000`.
6. Зарегистрируйтесь через `login.html`. После этого в SQL Editor выполните команду (замените email):
   `update public.profiles set role='admin' where id=(select id from auth.users where email='you@example.com');`
7. Войдите заново и откройте `admin.html`.

## Поведение
- `everyone`: любой гость и зарегистрированный участник отправляет статьи; они получают `pending`.
- `registered`: только вошедшие пользователи отправляют статьи.
- `admin`: отправка пользователями закрыта; администратор управляет существующими материалами.
- Только администратор одобряет, отклоняет и удаляет статьи. Проверки работают в базе через RLS, а не только в интерфейсе.
- На публичной странице видны только `published` статьи из Supabase.

## Важные ограничения перед публичным запуском
- Гостевая отправка в текущем MVP доступна напрямую через Supabase anon API. **До публичного запуска** необходимо добавить CAPTCHA/Turnstile и серверное ограничение частоты отправок через Edge Function, запретив прямую вставку гостями. Иначе возможен спам.
- Гости не могут отслеживать/редактировать свои отправленные статьи. Добавить одноразовые ссылки при необходимости.
- Демонстрационные данные каталога, участников и видео из исходного HTML оставлены без проверки; они не синхронизируются с Supabase.
- Форма обратной связи сохраняет сообщения в Supabase; администратор видит их в панели. Карточки видео пока демонстрационные: открывают поиск на YouTube, а не выдают тестовый ролик за настоящий обзор.
- В режиме `admin` интерфейс подачи закрыт для всех, включая админа: администратор управляет уже существующими материалами из панели.
- Для защиты от XSS статьи отображаются как обычный текст, без интерпретации HTML.

## GitHub Pages / PowerShell
Ветка разработки: `feature/admin-panel`. После проверки создайте Pull Request в `main`. GitHub Pages публикует файлы из корня ветки `main` (если выбран такой источник).

```powershell
cd "$HOME\Downloads\belgee-x80"
git switch -c feature/admin-panel
git add .
git commit -m "Unify BELGEE X80 design and admin panel"
git push -u origin feature/admin-panel
```

Если ветка уже создана, используйте `git switch feature/admin-panel` вместо `git switch -c`.

Общие стили всех страниц: `css/shared.css`. Секретные ключи нельзя хранить в публичном репозитории. Для реального публичного запуска гостевых публикаций обязательно настройте серверный антиспам (см. ограничения выше).

## Обновление существующего GitHub репозитория
Сначала распакуйте архив в отдельную папку. Скопируйте **содержимое** в локальный клон `BelgeeX80`, не копируя папку `.git` и не добавляя секреты. Выполните `git status`, затем `git add .`, `git commit -m "Refresh portal and moderation"`, `git push -u origin feature/admin-panel`. Откройте Pull Request и объедините с `main` только после настройки и проверки Supabase.

## Проверка перед объединением
1. В `js/config.js` заполните только Project URL и publishable/anon key.
2. Выполните полный `supabase/schema.sql` в SQL Editor (включая таблицу feedback).
3. Зарегистрируйте аккаунт и назначьте admin через SQL Editor; не выдавайте роль через интерфейс.
4. Проверьте отправку статьи гостем: статус `pending`, на публичной странице её нет.
5. Одобрите статью администратором: она видна всем.
6. Переключите режим `registered`: гость не может отправить статью, в том числе напрямую через Supabase API.
7. Проверьте, что обычный пользователь не может обновлять и удалять чужие статьи.
8. Проверьте отправку обратной связи и отображение в админ-панели.

**Антиспам:** скрытые поля форм — лишь базовая защита. Для публичного сайта с гостевыми публикациями обязательно добавить Turnstile + Edge Function с серверной проверкой токена и ограничением частоты. Пока этого нет, включите режим `registered` при появлении спама.
